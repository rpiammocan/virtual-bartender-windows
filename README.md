# Virtual Bartender for Windows

![Virtual Bartender](assets/virtual-bartender-icon.svg)

Windows desktop edition of Virtual Bartender.

## 🪟 Download for Windows

### ⬇️ [Open the latest Windows builds](https://github.com/rpiammocan/virtual-bartender-windows/actions/workflows/build-windows.yml)

Open the newest successful **Build Windows Installer** run, scroll to **Artifacts**, and download **VirtualBartender-Windows**. Extract the ZIP and run `VirtualBartender-Setup.exe`.

## Current features

- Cocktail and mocktail recipes
- My Bar inventory
- Tonight's Bar
- What Can I Make matching
- Clickable recipe links from every What Can I Make category
- Ingredient substitutions and recipe variants
- Shopping list and suggestions
- Favorites and history
- Surprise Me
- Local SQLite data
- Offline desktop operation

## Architecture

- Electron desktop shell
- React frontend
- FastAPI backend bundled as a standalone Windows executable with PyInstaller
- SQLite application data stored in the current Windows user's application-data folder
- Windows installer generated by Electron Forge / Squirrel.Windows

## Source snapshot

The source snapshot used by the Windows build is recorded in `source-pin.json`. Updating the CasaOS application does not update this pin automatically, keeping the Windows edition isolated from CasaOS changes until they are deliberately brought over.

## Windows data

Runtime data is kept outside the installed program in Electron's per-user application-data directory under `Virtual Bartender`:

- `data/bartender.db`
- `data/images/`
- `backups/`

This keeps user data separate from disposable application binaries.

## Build

The GitHub Actions workflow `.github/workflows/build-windows.yml` builds the Windows installer and uploads it as the **VirtualBartender-Windows** workflow artifact.

The build performs four stages:

1. Check out the pinned Virtual Bartender source snapshot.
2. Build the React frontend.
3. Bundle FastAPI/Python into `virtual-bartender-backend.exe` with PyInstaller.
4. Package the backend and Electron shell into a Windows installer.
