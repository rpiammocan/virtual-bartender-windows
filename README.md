# Virtual Bartender for Windows

Windows desktop edition of Virtual Bartender.

This repository is intentionally separate from the CasaOS/Docker application. Windows builds are based on an explicitly pinned snapshot of `rpiammocan/virtual-bartender`; changes to the CasaOS repository do **not** automatically alter this Windows application.

## Architecture

- Electron desktop shell
- Existing React frontend
- Existing FastAPI backend, bundled as a standalone Windows executable with PyInstaller
- SQLite application data stored in the current Windows user's application-data folder
- Windows installer generated by Electron Forge / Squirrel.Windows

## Source snapshot

The source snapshot used by the Windows build is recorded in `source-pin.json`. Updating the CasaOS application does not update this pin automatically.

## Windows data

Runtime data is kept outside the installed program in Electron's per-user application-data directory under `Virtual Bartender`:

- `data/bartender.db`
- `data/images/`
- `backups/`

This keeps user data separate from disposable application binaries.

## Build

The GitHub Actions workflow `.github/workflows/build-windows.yml` builds the Windows installer and uploads it as a workflow artifact.

The build performs four stages:

1. Check out the pinned Virtual Bartender source snapshot.
2. Build the React frontend.
3. Bundle FastAPI/Python into `virtual-bartender-backend.exe` with PyInstaller.
4. Package the backend and Electron shell into a Windows installer.

## CasaOS separation

The CasaOS/Docker version remains in `rpiammocan/virtual-bartender`. Windows-specific Electron, PyInstaller, installer, and Windows path changes belong only in this repository.
